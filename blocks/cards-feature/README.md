# cards-feature

Custom **cards** block. Purpose: grid of bordered link tiles, each an icon above a short label, linking to section landing pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: icon cell (image or :icon:) + label cell (a link); the whole tile is clickable.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
