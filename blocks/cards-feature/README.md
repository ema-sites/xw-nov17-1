# cards-feature

Custom **cards** block. Purpose: Grid of feature/CTA cards linking to key site sections.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: image in cell 1, linked title, short description and Learn More link in cell 2.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
