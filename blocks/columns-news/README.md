# columns-news

Custom **columns** block. Purpose: homepage area pairing the news list with quick-link and council-meeting link lists.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: rows of columns: a news cell (heading, teaser titles, summaries, Read more links) and link-list cells (heading + list of links; long lists flow into two columns).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
