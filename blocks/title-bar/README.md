# title-bar

Custom **custom** block. Purpose: panel header bar with a title and actions (e.g. Need help?) ending in a Share dropdown.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: title; row 2 (optional): action links. The Share dropdown is runtime UI drawn by the block.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
