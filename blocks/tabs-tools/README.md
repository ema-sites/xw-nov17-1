# tabs-tools

Custom **tabs** block. Purpose: row of icon tabs switching between tool panels (Calendar, What Goes Where, Game, Need help?).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: label cell (text, optional icon) + panel content cell. A panel whose only content is a link to a /fragments/ page loads that fragment, so a panel can hold blocks.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
