# breadcrumb

Custom **custom** block. Purpose: breadcrumb trail (Home, parent pages, current page) shown at the top of most content pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one cell with the trail: a list of links (or links in a paragraph); the last, unlinked item is the current page. Left empty, the trail is built from the URL path.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
