# cards-news

Custom **cards** block. Purpose: Text-only list of dated news items.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item: leave cell 1 empty (or add an image), date paragraph, linked title, abstract and Read More link in cell 2.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
