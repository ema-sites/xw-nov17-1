# video-date-select

Custom **custom** block. Purpose: the "Select a Date" dropdown that opens the chosen council meeting video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 (optional): label text; next row: list of links, link text = meeting date, URL = video.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
