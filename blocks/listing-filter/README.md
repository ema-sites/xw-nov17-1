# listing-filter

Custom **custom** block. Purpose: filter bar for a listing: category dropdown, optional keyword input and a GO button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: key/value rows: Select Name, Select Placeholder, Select Options (list), Keyword Name, Keyword Placeholder, Button, Action. Submitting navigates to Action with the values as query parameters.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
