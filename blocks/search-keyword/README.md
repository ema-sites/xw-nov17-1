# search-keyword

Custom **search** block. Purpose: keyword box with a GO / Search button sending the query to a search or lookup page (meetings, bylaws, address lookup).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: key/value rows, all optional: Label, Placeholder, Button, Action, Param.

## Supported variations

| Variation | Option class |
| --- | --- |
| Rounded | `rounded` |
| Blue 2 | `blue-2` |
| Wide (site search page) | `wide` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Rounded, Blue 2, Wide.
