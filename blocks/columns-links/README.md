# columns-links

Custom **columns** block. Purpose: Side-by-side groups of quick links, each with a heading and a link list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row; each cell holds an h2 plus a bulleted list of links; lists with more than 5 links split into two sub-columns.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
