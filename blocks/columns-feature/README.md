# columns-feature

Custom **columns** block. Purpose: fixed two-column pair: a text panel (heading, paragraph, bullets or link) beside a large photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with two cells: text cell + image cell (either order).

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Left Boxed Text | `image-left-boxed-text` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Image Left Boxed Text.
