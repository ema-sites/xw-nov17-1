# carousel-banner

Custom **carousel** block. Purpose: Rotating full-width promotional banners at the top of the home page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide: banner image in cell 1, optional heading/subtitle/link in cell 2.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
