# cards-teaser

Custom **cards** block. Purpose: list of teasers, each a photo beside a linked title, summary and optional "Learn more" link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per teaser: image cell + body cell (title link, summary, optional Learn more link).

## Supported variations

| Variation | Option class |
| --- | --- |
| Large Image | `large-image` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Large Image.
